# Addie's Physics Test 2 Mastery Hub 🚀

A personalized, interactive study web application created for Addie for **Conceptual Physics Test 2** (Dr. Greg Perugini, Rowan College of South Jersey).

Covering **Hewitt Conceptual Physics Chapters 5, 6, 7, and 8**:
- **Chapter 5**: Newton's Third Law of Motion
- **Chapter 6**: Momentum & Impulse
- **Chapter 7**: Energy, Work, and Power
- **Chapter 8**: Rotational Motion, Torque & Centripetal Acceleration

---

## 🎯 Tailored Specifically to Addie's Strengths & Needs

1. **Brute "When to Use This Formula" Memory Triggers**:
   - Matches keywords in exam questions (e.g. *"airbag / cushion"* $\to$ $F\Delta t = \Delta p$; *"collides and sticks"* $\to$ $(m_1+m_2)v_f = m_1 v_1 + m_2 v_2$; *"outer edge of cylinder"* $\to$ $a_c = v^2/r$) directly to the exact formula.
2. **Plain English Explanations**:
   - Zero confusing jargon. Straightforward analogies for why the right answer is right and why the trick distractors fail.
3. **Scaffolded Algebra Lifeline**:
   - Pre-rearranged algebraic forms for every formula so she never gets tripped up rearranging equations or solving for variables with square roots.
4. **Test 1 Pitfall / Trap Warnings**:
   - Explicit alert banners, including the `#1 Test 1 Trap`: Distinguishing horizontal motion (car braking) from vertical free fall ($g = 9.8\text{ m/s}^2$ is ONLY for vertical falling/gravity!).

---

## 📱 Features

- **🎯 Formula Matchmaker**: Rapid-fire flashcard drill testing which formula to grab from word clues.
- **🧮 Scaffolded Math Lab**: Interactive problem generator with live randomizers, given/need breakdowns, pre-rearranged formula lifelines, and instant step-by-step arithmetic explanations.
- **💡 Conceptual Question Bank**: 40 Hewitt practice exam questions covering Chapters 5, 6, 7, and 8 (10 per topic) with instant verification, plain English explanations, and professor trick warnings.
- **🚨 Test 2 Trap Alerts**: 5 high-alert traps tested heavily on college physics exams.
- **📋 Formula & Algebra Cheat Sheet**: Complete reference table with every formula pre-solved for every variable.
- **📱 Fully Responsive**: Works seamlessly on iPhone, iPad, and laptop. Progress is saved automatically to browser storage.
